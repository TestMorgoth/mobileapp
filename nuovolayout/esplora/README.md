# Comuni App – Restyle concept

Questo pacchetto contiene una proposta di ricostruzione da zero della pagina /app/,
reinterpretata con il linguaggio visivo già sviluppato nelle altre schermate:
- palette scura bronze/gold
- look & feel premium / atmosferico
- approccio editoriale + assistant-first
- layout responsive senza shell telefono
