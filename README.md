# @territorio/mobile-cordova

Canale visitatore React/Vite con target Cordova. La build web usa `base: '/app/'`.

## Moduli reali

- Home, explore, POI, eventi, itinerari.
- Search e discovery via `api-core`.
- Assistant con sessione locale e feedback.
- Planner, mappa Google Maps, preferiti locali, profilo, accessibilità, impostazioni e legal.

## Env client

- `VITE_API_BASE_URL` opzionale.
- `VITE_TENANT_SLUG` opzionale.
- `VITE_GOOGLE_MAPS_API_KEY` opzionale per attivare Google Maps JS API.

## Gap noti

Offline avanzato e rilascio Cordova nativo non sono completati.
